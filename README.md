# Amol Rathod Portfolio

A polished personal portfolio for Amol Rathod, a technical consultant and frontend specialist. The site presents selected work, certifications, services, writing, and contact paths through a fast, responsive Next.js experience.

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React and Iconify

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

## Scripts

```bash
npm run dev        # Start the local development server
npm run build      # Create a production build
npm run start      # Serve the production build
npm run lint       # Run ESLint
npm run type-check # Run TypeScript checks
npm run analyze    # Build with bundle analysis enabled
```

## Deployment

This portfolio is intended to deploy on Vercel from GitHub. The production domain is:
